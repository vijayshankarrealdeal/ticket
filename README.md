# Ticket System

A React + Vite dashboard for a multi-channel ticket system.

## Pages

- **Platforms** — connect channels (WhatsApp, Email, Slack, Web, etc.)
- **Ticket Status** — filterable ticket list with status counts
- **Conversations** — live chat view with thread list
- **Agent Builder** — configure an AI support agent (model, tools, persona)
- **Settings** — profile, workspace, notifications, security, billing

## Run

```bash
npm install
npm run dev
```

Opens on http://localhost:5173.

## Build

```bash
npm run build
npm run preview
```
